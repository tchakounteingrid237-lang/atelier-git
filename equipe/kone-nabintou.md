## Quiz

1. Juste après `git commit`, où se trouve mon commit ?

   **Réponse :** Uniquement dans l'historique local, c'est-à-dire dans mon Codespace. GitHub ne le connaît pas encore.

2. Juste après `git push`, où se trouve-t-il ?

   **Réponse :** Il est à la fois dans mon Codespace et sur GitHub, donc visible par les autres membres de l'équipe, qui peuvent le récupérer avec `git pull`.

3. Que se passe-t-il si je supprime mon Codespace après un commit mais sans push ?

   **Réponse :** Le commit est perdu, car il n'existait que dans le Codespace. Comme rien n'a été envoyé sur GitHub, il n'y a aucune copie pour le récupérer.
