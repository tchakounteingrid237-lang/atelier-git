## Quiz

1. Juste après `git commit`, où se trouve mon commit ?
Dans l'historique local de mon Codespace, pas encore sur GitHub.

2. Juste après `git push`, où se trouve-t-il ?
Sur GitHub, et toujours dans mon Codespace.

3. Que se passe-t-il si je supprime mon Codespace après un commit mais sans push ?
Le commit est perdu, car il n'existait que dans mon Codespace.

## Stash

git stash met de côté les modifications en cours, sans les commiter.
On retrouve ensuite un dossier de travail propre pour traiter une urgence.
git stash pop remet les modifications rangées là où on les avait laissées.
